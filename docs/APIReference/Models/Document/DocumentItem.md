# DocumentItem

## Descripción

Línea de producto de un *[CustomerDocument](CustomerDocument.md)*.

*Disponible desde la versión 2.9.1.*

## Métodos

- **int** getProductId(): id del producto.
- **String** getName(): nombre del producto guardado en el documento.
- **String** getSku(): SKU de la combinación; *null* si no tiene.
- **int** getQuantity(): cantidad.
