# PriceView

## Descripción

Importe con su moneda, usado donde pueden convivir importes de varias monedas (el catálogo).

*Disponible desde la versión 2.8.5.*

## Métodos

- **long** getAmount(): importe redondeado una vez a unidades menores de *getCurrencyCode()*.
- **String** getCurrencyCode(): código ISO 4217 en mayúsculas.
