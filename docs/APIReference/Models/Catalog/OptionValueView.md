# OptionValueView

## Descripción

Valor de una opción combinable.

*Disponible desde la versión 2.9.0.*

## Métodos

- **int** getOptionValueId(): id del valor de opción, el que usan *getOptionValueIds()* de *CombinationView* y de *RowChange*.
- **String** getValue(): texto del valor en el idioma del contexto.
