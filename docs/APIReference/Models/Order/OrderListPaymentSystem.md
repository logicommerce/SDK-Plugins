# OrderListPaymentSystem

## Descripción

Método de pago de un pedido en los listados. Forma parte de *[OrderList](OrderList.md)*.

Disponible desde la versión **2.8.5** del SDK.

## Métodos

- **Integer** getPaymentSystemId()
- **Integer** getPaymentSystemPluginId()
- **String** getName()
- **[PaymentType](../../Enums/README.md#PaymentType)** getPaymentType()
- **String** getProperty()
- **double** getPrice()
- **[AmountType](../../Enums/README.md#AmountType)** getIncreaseType()
- **double** getIncreaseValue()
- **double** getIncreaseMin()
