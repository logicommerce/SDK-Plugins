# OrderListCustomerInvoicingAddress

## Descripción

Dirección de facturación del cliente de un pedido en los listados. Forma parte de *[OrderListCustomer](OrderListCustomer.md)*.
Extiende de **[OrderListCustomerAddress](OrderListCustomerAddress.md)**

Disponible desde la versión **2.8.5** del SDK.

## Métodos

- **boolean** isRe(): Aplica recargo de equivalencia.
- **boolean** isTax(): Aplica impuestos.
